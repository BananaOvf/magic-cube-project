Управление клавиатурой:
  R, U, F, D, L, B — поворот грани по часовой стрелке
  + Shift — против часовой
  + Ctrl — широкий ход (грань + средний слой)
  + Ctrl+Shift — широкий против часовой
  M, E, S — поворот среднего слоя (с Shift — обратное)
  x, y, z — вращение всего куба (с Shift — обратное)
  ← (Отмена) / → (Повтор) — навигация по истории ходов

Пробел — таймер:
  • Удерживайте Пробел ~1 секунду (появится прогресс-бар), затем отпустите — таймер запустится
  • Повторное нажатие Пробела — остановка таймера и сохранение сборки

Мышь:
  • Зажмите левую кнопку и двигайте — вращение камеры
  • Колёсико — приближение/отдаление

Меню:
  Вид → Сжатая история — компактное отображение последовательности ходов
  Вид → Сплеш-скрин при старте — показывать заставку при запуске
  Команды → Сброс — собрать куб (исходное состояние)
  Команды → Запутать — случайный скрамбл (20 ходов)
  Команды → Сброс камеры — вернуть камеру в исходное положение
  Команды → Собрать → [название решателя] — автоматическое решение выбранным алгоритмом
  Экспорт → Excel — сохранить список сборок в файл .xlsx

Панель слева:
  • Список всех сборок с временем, скрамблом и решением (подсказка при наведении)
  • Кнопка ✕ — удалить выбранную сборку
  • Слайдер «Скорость анимации» — регулирует темп поворотов (0.1x – 50.0x)

Строка текущего хода подсвечивает выполняемую операцию; при решении через солвер показывается кнопка «Стоп».
